# Install (2 minutes)

**Need:** Claude Pro (or higher) plan + Claude desktop app on Mac or Windows laptop.

1. Unzip `video-editor.zip`. You get a folder named `video-editor`.
2. Move that folder into your Claude skills folder:
   - **Mac:** `~/.claude/skills/` (Finder → Go → Go to Folder → paste `~/.claude/skills` — create the folder if missing)
   - **Windows:** `C:\Users\<your-name>\.claude\skills\`
3. Make a new empty folder anywhere, e.g. `Desktop/My Edits`.
4. Open Claude desktop → **Code** tab → choose that folder → Trust.
5. Type **`/video-editor`** and press Enter.

That's it. The editor asks you everything else:
1. sends you a reel you like (link or file),
2. you drop your raw video,
3. you get the edited video in the `exports` folder.

First run installs free tools (ffmpeg, Node.js, Whisper) automatically — just click **Allow** when asked.
